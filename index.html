Elegí según la memoria de tu equipo

La descarga puede superar 1 GB según el modelo. Usá Wi-Fi; necesita memoria y un navegador compatible. Sin cuentas ni API de pago.

IAbrian usa WebLLM y modelos Qwen2.5. El equilibrado mejora la capacidad frente al modelo ligero, pero necesita más memoria. El modelo de 3B es más exigente. Ninguno garantiza respuestas correctas. La búsqueda funciona sin GPU; la conversación local necesita WebGPU.

La primera activación descarga archivos externos desde proveedores como jsDelivr, Hugging Face y GitHub. Estos servicios reciben datos de conexión; el modelo genera las respuestas localmente. En modo «Buscar en la web», o cuando «Automático» detecta una consulta actual, se envía a Tavily la búsqueda indicada o la pregunta actual; en repreguntas pueden incluirse hasta tres preguntas anteriores para identificar el tema, pero no las respuestas del chat. Tavily recibe datos de conexión y se aplican sus políticas. El acceso gratuito tiene límites, sin una cuota ilimitada garantizada.

La búsqueda devuelve extractos de páginas indexadas y enlaces. No accede a todo internet ni garantiza información actual o correcta. Límites del buscador · Privacidad de Tavily

El historial se guarda en este navegador, sin sincronización. Borrar el historial no elimina la caché del modelo: para eso, borrá los datos del sitio desde tu navegador.

La velocidad depende del equipo. No se cobra por pregunta; se consumen datos, batería y almacenamiento del dispositivo.
