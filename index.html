Tu IA, en tu dispositivo.

IAbrian usa WebLLM y un modelo Qwen2.5 de 0.5B parámetros. Es una IA pequeña: tiene límites de calidad y memoria y no equivale a ChatGPT.

La primera activación descarga archivos externos desde proveedores como jsDelivr, Hugging Face y GitHub. Estos servicios reciben datos de conexión; el modelo genera las respuestas localmente. Al activar «Consultar internet · Wikipedia», se envía a Wikipedia el tema indicado o la pregunta actual para buscar artículos; el historial no se envía.

El historial se guarda en este navegador, sin sincronización. Borrar el historial no elimina la caché del modelo: para eso, borrá los datos del sitio desde tu navegador.

La velocidad depende del equipo. No se cobra por pregunta; se consumen datos, batería y almacenamiento del dispositivo.
